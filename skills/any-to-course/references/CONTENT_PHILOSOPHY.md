# Content Philosophy

写课件和写文章不一样。一张幻灯片是 **演讲的视觉锚点**，不是给人当作小说读的。出测验也不是"考记忆力"，是"检验理解"。这份指南帮你避开最常见的坑。

---

## 幻灯片文案

### 一页一观点
每张片回答 **一个问题**。如果发现一张片里有两个并列观点，拆成两张。

**反例**：
> # 数据结构与算法
> - 数组 vs 链表 vs 哈希表 vs 树 vs 图
> - 时间复杂度 O(1) O(log n) O(n) O(n log n)
> - 空间-时间权衡

**正例**：拆成 4 张，每张讲一个数据结构 + 一句"什么时候用它"。

### 宁少勿多
- 每页 **≤ 3 个要点**，每个要点 **≤ 15 字**（中文）/ **≤ 10 词**（英文）
- 长段落必须 **提炼** 成要点，不是缩写——是抽取本质
- 多余信息不是"完整性"，是噪音

### 标题是结论
标题写 **观点**，不是 **主题**。

| 主题型（差） | 观点型（好） |
|---|---|
| 缓存策略 | 缓存是用空间换时间 |
| 错误处理 | 让程序"主动崩"比"硬撑"更安全 |
| 数据库范式 | 反范式不是错，是权衡 |

### 关键词高亮
每页选 **1–3 个关键词** 加 `<span class="accent">` 着重。多了就等于没有。

### 不要把代码当装饰
代码块只放真正会讲解的代码。**没解释的代码 = 干扰**。如果只想点一下"这是个例子"，用一行伪代码就够。

### 用动词开头的列表，不要名词开头
- ❌ "用户登录" / "用户行为分析" / "数据可视化"
- ✅ "登录后立即推送" / "分析用户行为" / "把数据画出来"

## 何时插入互动元素

| 元素 | 何时用 | 何时别用 |
|---|---|---|
| **Tooltip** | 引入"非常识术语"的那张片，第一次出现时加 | 在已经定义过的术语上重复加（噪音） |
| **Diagram** | 讲流程、对比、关系、层级时 | 内容是观点而非结构时（diagram 是结构的可视化） |
| **Animation** | 想强调"步骤"或"流动"时 | 每张片都加（眩晕） |
| **Inline Quiz** | 讲完一个概念后立即检验 | 课件最后一页（最后用独立测验页） |
| **Callout** | 真正需要"额外提醒"时 | 当装饰用 |

**经验法则**：互动元素是 **下限不是配额**。SKILL.md 说"至少 1 个 quiz / 至少 1 个 diagram"，意思是不能少；不是说一定要硬塞。

## 术语 Tooltip 的选择

**该加 tooltip 的**：
- 行业黑话（"过拟合"、"反范式"、"幂等"、"零信任"）
- 缩写第一次出现（"NLP"、"LLM"、"RAG"、"CDN"）
- 跨学科借用的概念（"熵"、"耦合"、"信噪比"）

**别加 tooltip 的**：
- 大众已知的（"HTML"、"邮件"、"密码"）
- 在原文里已经被解释过的（避免重复）
- 太常见以至于加了反而显得啰嗦的

## SVG 示意图选哪个结构？

| 内容形态 | 用哪个 |
|---|---|
| A → B → C 的顺序 | `dia-flow`（流程箭头） |
| 旧方式 vs 新方式 | `dia-compare`（对比双栏） |
| 父-子-孙的归属 | `dia-tree`（层级树） |
| 三五个概念互相影响 | `dia-net`（关系网） |

如果一个内容你想了 30 秒还没决定用哪种 diagram，**说明它根本不适合做 diagram**，写成文字要点就好。

## 测验出题原则

### 1. 考理解，不考记忆

**记忆题（不要出）**：
> Q: 文中作者把 "X" 比作什么？
> A. 河流  B. 火焰  C. 镜子  D. 桥

**理解题（要出）**：
> Q: 下列哪个场景最适合用作者讲的 X 模式？
> A. 高并发但低一致性要求的写入  B. 强一致性的金融交易  C. 单机批处理任务  D. 离线数据分析

### 2. 干扰项要"像但不对"

- 不要写 "以上都对" / "以上都不对" / "看情况"，那是偷懒
- 不要写明显荒谬的选项当对照
- 错的选项应该是 "如果学生只看过表面没理解本质，会选的那个"

### 3. 多选要真的"多选"

如果一道 multi 题答案只有 1 个，那就改成 single。`multi` 的答案数量 ≥ 2，让学生真的要做判断。

### 4. 解析至少回答一个问题

- "为什么这个对"
- "为什么其他错"
- "在什么场景下别的选项也可能对"

光写 "答案是 B" 等于没解析。

### 5. 题目分布要均匀

如果课件 8 张片，不要前 3 张出 8 道题、后 5 张一道没有。按章节均匀分配，让学生意识到每一段都重要。

### 6. 出题数对应内容长度

| 原文长度 | 题数 |
|---|---|
| < 1500 字 | 8–10 |
| 1500–5000 字 | 10–15 |
| > 5000 字 | 15–20 |

**绝不超过 20 题**——再长的内容也不需要更多，超过 20 题做完会失去耐心。

---

## 语言一致性

- 输入是中文 → 课件和测验完全中文，包括按钮文字、错误提示、解析
- 输入是英文 → 同理全英文
- **绝不混杂**。除非原文里本身就有外语术语（如 "Transformer"），那时候直接保留即可
- 中文里数字、单位用半角（`5 张`、`100 ms`），不要全角

---

## 视觉密度自检

写完每张 slide 后，问自己三个问题：
1. 这张片删掉一半内容，还能讲清吗？如果能，**删一半**
2. 我能用一句话向朋友讲清这张片的意思吗？如果不能，**重写**
3. 这张片有没有"装饰性"内容？如果有，**去掉**

## 速查清单

生成完一份课件 + 测验后，对照检查：

**课件**：
- [ ] 总片数在 6–15 之间
- [ ] 每页 ≤ 3 个要点，标题是观点不是主题
- [ ] 至少 1 个 agenda、1 个 diagram、1 个 inline quiz、3 个 tooltip
- [ ] outro 有「开始测验」按钮，链接正确
- [ ] 语言与输入一致

**测验**：
- [ ] 题数在 8–20 之间
- [ ] 每题考理解不考记忆
- [ ] 每题都有解析
- [ ] multi 题答案确实 ≥ 2
- [ ] 题目按章节均匀分布
- [ ] 语言与课件一致
