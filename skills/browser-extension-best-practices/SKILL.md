# 浏览器插件最佳实践

其他项目要学习或落地这些实践时，先读 [实践指南](references/guide.md)。只打开和当前问题对应的专题。

| 当前问题 | 读取 |
| --- | --- |
| 技术栈、项目结构、国际化、组件样式、状态管理 | [架构与界面](references/architecture-and-ui.md) |
| 工程质量、版本记录、配置迁移 | [质量与演进](references/quality-and-evolution.md) |
| README、Agent 文档、按需文档 | [文档](references/documentation.md) |

只要求分析或方案时，交付指南中的决策与验收标准。用户点名某一档并要求修改后，才改目标项目。

来源工具、目录和依赖版本不是目标项目的标准。已有等价能力时保留现状。
