# Offline source principles

Source: [Rethinking skills and prompts for GPT-6 Astra](https://developers.openai.com/blog/rethinking-skills-and-prompts-for-gpt-6-astra), Eric Provencher, September 11, 2026. Reviewed September 13, 2026. This is a paraphrased decision map, not an article copy. No network retrieval is needed.

| Article topic | Decision principle |
| --- | --- |
| Opening premise | Reassess accumulated instructions as model capabilities change. |
| Better skills: discovery | Skill names and descriptions consume context; oversized catalogs can truncate descriptions and impair selection. |
| Better skills: triggers | Use concise, specific triggers; conflicting or expansive descriptions activate irrelevant workflows. |
| Better skills: disclosure | Route substantial workflows to relevant resources instead of loading everything. |
| Better skills: procedures | Avoid rigid recipes where judgment suffices; consider contributors using other models. |
| Up-to-date AGENTS.md: reading | Reassess persistent rules; connect maintained documentation to relevant tasks. |
| Up-to-date AGENTS.md: checking | Generic testing encouragement can cause excessive checking; explicitly describe verified safe local workflows. |
| Decision boundaries | Reconsider obsolete approval language without confusing model capability with authorization. |
| Persistence: completion | Specify the requested implementation, execution, inspection, and repair needed for completion; reconsider unnecessary first-pass review stops. |
| Persistence: exploration | Bound further exploration and stopping; an agent can perform the cleanup audit. |
